# DE2Sim Submission Demo

Open `demo_dashboard.html` directly or run `Launch_DE2Sim_Demo.bat` on Windows.

Army Training Verse — Challenge II: Intelligent Simulation Pipeline

DE2Sim demonstrates an end-to-end Challenge II pipeline that transforms standards-based digital-engineering artifacts into a validated ASOT, human-approved AI-assisted behavior, and executable low- and high-fidelity simulation outputs.

This package is self-contained and uses relative links only. It demonstrates readable-to-runnable engineering flow through ingestion, parsing, CAD geometry transformation, ASOT, provenance, behavior approval, simulation, and requirement evidence.
